/auth - Authentication

POST /company - Select company
GET /success - OAuth callback
POST /guest - Generate guest token
POST /revoke - Revoke token
GET /check-status - Check auth status

/sessions - Roleplay Sessions

GET / - List sessions
POST / - Create session
POST /:id/roleplay - Roleplay action
POST /:id/assessment - Get assessment
GET /:id/persona - Get persona
GET /:id/report - PDF report

/feedback - Session Feedback

POST /generate - Generate feedback
GET /:sessionId - Get feedback

/call-analysis - Call Analysis

POST /upload - Upload audio
GET /:id - Get analysis
POST /:id/assess - Assess call

/livekit - Real-time Voice

POST /token - Get room token
POST /roleplay - Start voice roleplay

/manage - Admin Management

GET /users - List users
GET /modules - List modules
GET /scenarios - List scenarios

/standings - Performance

GET /configuration - Get config
GET /summary - Get summary
